# Roadmap

## Shippable Product

Consists of two parts/windows - a user textbox for typing and configuring
the application, and a display for integrating into OBS.

When user types into a textbox and presses Enter,
the text string is sent to the display window, where it will appear
word-by-word with a little sound effect and fades out after some time
has passed.

For the most basic usage, a black-on-white display with options to configure
text layout, font and font size should be present.
